📖 Hướng dẫn sử dụng

  1. Đăng nhập hoặc đăng ký tài khoản (có thể dùng Google).
  2. Tải lên file câu hỏi định dạng .docx.
  3. Chọn số lượng câu hỏi, mức độ, số mã đề cần sinh.
  4. Nhấn “Tạo đề” và chờ hệ thống xử lý.
  5. Tải về file ZIP chứa tất cả mã đề & đáp án.
Lưu ý:
  • File câu hỏi cần soạn đúng định dạng (Câu hỏi + Đáp án A/B/C/D).
  • Nếu hệ thống báo lỗi, hãy kiểm tra lại định dạng file trước khi upload.
